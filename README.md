# Zyke

Zyke was an AI marketing agent built at IIT Kharagpur in 2024. It learned a brand's voice, tracked what was trending, and turned both into finished social posts with AI-generated images that could be edited by clicking on them. The company wound down in 2025.

This repository is the home for everything that is left of it:

- **`main`** — the current site at [zyke.in](https://zyke.in): a static page that explains what Zyke was, what it did, how it worked, with the product demo video. Built with Next.js 14 and exported as plain HTML.
- **Legacy branches** — the older codebases, kept intact with their full git history:

| Branch | What it is | Dates | Notes |
|---|---|---|---|
| `legacy/zyke-frontend-app` | The version 1.0 Next.js web app (auth, brand voice wizard, idea generator, post generation, click-to-segment editing, Razorpay credits) plus its DOC.md | Oct 2024 – Aug 2025 | This is what `main` looked like before the site was rebuilt. Identical to the former `rupammahato/zyke-new-2` repo plus two documentation commits. |
| `legacy/zyke` | The original July 2024 product: one Flask route and a hand-written HTML/JS page with a five-stage prompt chain | Jul – Oct 2024 | Was `Tasmay-Tibrewal/Zyke`. Its backend ran at flask.app.zyke.in. |
| `legacy/zyke-vercel` | A standalone one-page marketing site made for Vercel | Oct 2024 | Was `rupammahato/zyke-vercel`. |

Repos that were **not** brought in, because they are strict subsets of a branch above:

- `zyke-new-2` is the first 32 commits of `legacy/zyke-frontend-app` (same commit hashes).
- `zyke-new` is `zyke-new-2` before its history was rewritten to remove a committed `.env`. It is deliberately not pushed here because it contains real secrets.
- `Zyke-Team` is a byte-identical copy of three snapshots of `legacy/zyke`.
- `zyke-backend` (the Flask + MongoDB API behind the app) is a separate repository at `rupammahato/zyke-backend`.

## Working on the site

```bash
npm install
npm run dev        # http://localhost:3000
npm run build      # writes the static site to ./out
```

All copy and data for the page is in `lib/content.ts`. Sections are in `components/landing/`. Images under `public/posts`, `public/generated` and `public/masks` were generated by Zyke during the demo run.

## Deploying

Every push to `main` runs `.github/workflows/deploy-pages.yml`, which builds the site and publishes `./out` to GitHub Pages.

One-time setup:

1. In the repository settings, open **Pages** and set **Source** to **GitHub Actions**.
2. Under **Custom domain**, enter `zyke.in` (the `public/CNAME` file already contains it).
3. At the DNS provider for `zyke.in`, add `A` records for the apex pointing at GitHub Pages (`185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`) and a `CNAME` for `www` pointing at `zykelabs.github.io`.
4. Turn on **Enforce HTTPS** once the certificate is issued.

The `out/` folder is plain static files, so it can equally be dropped onto Vercel, Netlify, Cloudflare Pages or an S3 bucket if GitHub Pages is not wanted.

## What is on the page

Eleven numbered sections: the demo video with chapter links, the problem, the three
promises plus the competitor comparison, the four-step walkthrough with the real
click-to-edit before and after, the thirteen features, the work Zyke generated, who it
was for, the unit economics and market sizing, the image pipeline and what was new
about it, the story with the team and the grants, and why it started and why it stopped.

`lib/content.ts` holds every piece of copy and data. The components are presentational.

### Where the content comes from

- The demo video, its chapter list and the thirteen-feature list come from the
  November 2024 product demo on YouTube.
- The problem, the buyer quotes, the comparison table, the pricing, the market figures
  and the grants come from the December 2024 pitch deck, with Y Combinator, Modal,
  Daytona and Google Cloud added afterwards. The total is $54,500 in credits.
- The stack, the trend recommender and the generation pipeline come from the backend and
  frontend source, documented in full in `../docs/repos/`.
- The editing pipeline is the one part not preserved. The archived backend has only the
  Stability inpaint proxy and the OpenCV mask blender; the router, GraCo segmentation,
  Grounding DINO and the styling LoRAs ran as a separate GPU service behind Cloud Run
  whose source is not in these repos. The page says so where it describes it.
- The ambition and the post-mortem in section 11 are the founders' own words.

### The gallery

`public/gallery/` holds 35 images Zyke generated during testing for Zomato, Bira 91,
Nike and a coding school, chosen from 77 by eye.

They are organised by month, not by brand, because the month is the story. Resolution
tracks it: September is entirely 512px with text that collapses into letter shapes,
October moves to 512 and 1024 as short headlines start landing, and November runs at
1024 and 1600 with full sentences, correct logos and the same idea reproducible across
two formats. `nov-better-food-first-run` and `nov-better-food-second-run` are two runs
of one idea minutes apart and are shown side by side as the clearest evidence of that.

Each month shows six images with a button to reveal the rest, and the three cards at the
top of the section jump straight into a given month.

The two Nike images arrived as UI screenshots and were cropped with ffmpeg to remove the
browser chrome and the carousel arrows.
